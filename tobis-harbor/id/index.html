DukunganKebijakan Privasi

Bantu Tobi menghidupkan kembali pelabuhan tepi laut yang sedang terlelap dengan menyortir kargo, mengosongkan rak, dan memperbaiki dermaga. Game puzzle santai yang bisa kamu mainkan beberapa menit sehari, bahkan secara offline.

Dukungan

Punya pertanyaan, laporan bug, atau ide? Kirim e-mail ke heyoggi.games@gmail.com. Sertakan model perangkat dan versi game kamu (Pengaturan → bagian bawah layar). Kami biasanya membalas dalam 2 hari kerja.

Pertanyaan umum

Di mana progresku disimpan?

Hanya di perangkatmu. Game ini tidak memiliki akun maupun simpanan cloud, jadi menghapus instalasi game akan menghapus progresmu (di Android, salinannya mungkin kembali dari cadangan sistem Google jika fitur itu aktif).

Bagaimana cara memulai game dari awal?

Pengaturan → Atur ulang progres. Game akan meminta konfirmasimu terlebih dahulu. Pengaturan suara, bahasa, dan berbagi data kamu tetap disimpan.

Bagaimana cara berhenti membagikan statistik permainan atau menghapusnya?

Pengaturan → matikan Berbagi data; sejak saat itu tidak ada statistik yang dikirim. Pengaturan → Hapus dataku akan meminta Unity Analytics menghapus statistik anonim yang terkait dengan game-mu; biasanya proses ini selesai dalam 30 hari. Lihat Kebijakan Privasi untuk detailnya.
