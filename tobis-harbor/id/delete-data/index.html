Hapus data Tobi's Harbor kamu

Tobi's Harbor tidak punya akun dan tidak perlu mendaftar: kami tidak pernah meminta nama atau email kamu. Satu-satunya data yang keluar dari ponselmu adalah statistik permainan anonim, dan itu pun hanya jika kamu setuju untuk membagikannya. Berikut cara menghapus semuanya.

Statistik permainan anonim

  1. Buka Tobi's Harbor dan masuk ke Pengaturan.
  2. Ketuk Hapus dataku. Game akan meminta Unity Analytics menghapus semua statistik yang terkait dengan ID instalasi acak game-mu dan mematikan Berbagi data. Unity biasanya menyelesaikan penghapusan dalam 30 hari.

Jika kamu hanya ingin berhenti mengirim statistik, matikan Berbagi data di Pengaturan.

Progres game di ponselmu

Progresmu hanya disimpan di perangkatmu. Pengaturan → Atur ulang progres akan menghapusnya dan memulai game dari awal. Menghapus instalasi game juga akan menghapusnya (di Android, salinannya mungkin tetap ada di cadangan sistem Google kamu jika fitur itu aktif).

Jika kamu sudah tidak punya game-nya

Tanpa game-nya, kami tidak bisa mengetahui statistik mana yang milikmu, karena statistik itu hanya membawa ID instalasi acak, tanpa nama, email, atau ID perangkat. Statistik itu terhapus otomatis saat masa penyimpanan Unity berakhir (peristiwa mentah paling lambat setelah 1 tahun). Pertanyaan: heyoggi.games@gmail.com.
