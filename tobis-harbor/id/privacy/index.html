Tobi's Harbor — Kebijakan Privasi

Tanggal berlaku: 10 Oktober 2026 · Pengembang: HeyOggi Games

Ini adalah terjemahan. Jika ada perbedaan dengan versi bahasa Inggris, yang berlaku adalah versi bahasa Inggris.

Tobi's Harbor ("game") adalah game puzzle pemain tunggal yang juga bisa dimainkan offline. Kebijakan ini menjelaskan data apa yang dikumpulkan game, untuk apa, berapa lama data disimpan, dan hak apa saja yang kamu miliki atas data tersebut.

1. Data yang kami kumpulkan

Tanpa akun, tanpa pendaftaran. Game ini tidak pernah meminta atau mengumpulkan nama, alamat e-mail, nomor telepon, lokasi, kontak, atau foto kamu.

Progres game (hanya di perangkatmu). Bintang, emas, nyawa, level yang sudah selesai, tugas pelabuhan, pengaturan, dan status tutorial disimpan dalam sebuah file di perangkatmu. File ini tidak dikirim ke kami. Menghapus instalasi game akan menghapus file tersebut (di Android, jika pencadangan sistem aktif, salinannya mungkin tetap ada di cadangan akun Google-mu dan tunduk pada kebijakan privasi Google).

Statistik permainan anonim (hanya dengan persetujuanmu). Untuk menyempurnakan game, dan hanya setelah kamu menyetujuinya saat pertama kali membuka game (kamu bisa mengubah pilihanmu di Pengaturan kapan saja), kami mengumpulkan peristiwa dengan jenis berikut melalui Unity Analytics (Unity Technologies, "Unity Gaming Services"):

  • peluncuran aplikasi, jumlah hari sejak instalasi, versi aplikasi;
  • awal dan akhir level: nomor level, hasil (menang / kalah / keluar), sisa langkah, waktu yang dihabiskan, percobaan ke berapa, booster yang dipakai, petunjuk yang ditampilkan;
  • perubahan mata uang dalam game (bintang, emas, nyawa) beserta alasannya;
  • tugas pelabuhan yang diselesaikan, langkah tutorial, petunjuk yang ditampilkan;
  • penawaran iklan berhadiah yang ditampilkan, dimulai, diselesaikan, atau gagal;
  • perubahan pengaturan suara / musik / getar / petunjuk.

Peristiwa ini dikirim bersama ID instalasi acak yang dibuat di perangkatmu saat game pertama kali dibuka. ID ini tidak mengidentifikasi kamu, perangkatmu, atau akunmu di aplikasi lain; menginstal ulang game akan membuat ID baru. Unity Analytics juga memproses informasi teknis seperti model perangkat, versi sistem operasi, negara (ditentukan dari alamat IP, yang tidak disimpan), bahasa, dan waktu sesi. Detail: kebijakan privasi Unity (unity.com/legal/privacy-policy) dan deskripsi pemrosesan data Unity Gaming Services.

Jika kamu menolak, tidak ada statistik yang dikirim sama sekali; game tetap berjalan seperti biasa.

2. Mengapa kami menggunakan data

  • Untuk melihat level mana yang terlalu sulit atau terlalu mudah dan memperbaiki keseimbangannya.
  • Untuk menemukan bug dan bagian tempat pemain sering tersendat.
  • Untuk memahami seberapa sering penawaran iklan berhadiah digunakan.

Data tidak digunakan untuk membuat profil iklan dan tidak dijual kepada pihak ketiga.

3. Iklan

Game ini hanya memiliki penempatan iklan berhadiah (pemain sendiri yang memilih untuk menonton: +5 langkah, +1 nyawa, emas berlipat dua). Saat ini game tidak berisi SDK jaringan iklan apa pun dan tidak menampilkan iklan, jadi tidak ada ID iklan yang dikumpulkan. Saat jaringan iklan ditambahkan, bagian ini dan formulir keamanan data di toko aplikasi akan diperbarui, dan layar persetujuan dalam game akan diperluas sesuai dengan itu.

4. Masa penyimpanan

  • Progres game: di perangkatmu sampai kamu menghapus instalasi game.
  • Statistik anonim: di Unity Analytics selama masa penyimpanan standar Unity setelah dikumpulkan (peristiwa mentah hingga 1 tahun; laporan agregat dapat disimpan lebih lama).

5. Hak-hakmu dan permintaan penghapusan

  • Menarik persetujuan: Pengaturan → matikan "Berbagi data". Sejak saat itu tidak ada peristiwa yang dikirim.
  • Menghapus datamu: Pengaturan → "Hapus dataku". Game akan mengirim permintaan ke Unity Analytics untuk menghapus semua data analitik yang terkait dengan ID instalasimu dan mematikan persetujuan. Unity biasanya menyelesaikan penghapusan dalam 30 hari.
  • Untuk menghapus progres game lokal, hapus instalasi aplikasi.
  • Pertanyaan dan permintaan: heyoggi.games@gmail.com

Melalui alamat ini kamu dapat menggunakan hak akses, perbaikan, penghapusan, keberatan, dan portabilitas data yang diberikan oleh GDPR, UK GDPR, KVKK Turki, dan undang-undang serupa.

6. Anak-anak

Game ini ditujukan untuk khalayak umum dan tidak dengan sengaja mengumpulkan data pribadi dari anak-anak. Analitik hanya berjalan dengan persetujuan eksplisit dan tidak berisi data pribadi. Jika kamu yakin data seorang anak terkumpul secara tidak sengaja, kirimkan pesan ke alamat di atas dan kami akan menghapusnya.
